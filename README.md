# tag-download

A single web page that downloads the accelerometer log from a `BLE_TAG` over Web Bluetooth, or clears it.

Open the GitHub Pages site in Chrome or Edge (Android, Windows, macOS, ChromeOS). On iPhone, use the Bluefy browser. In Brave, turn on `brave://flags/#brave-web-bluetooth-api`. On Linux, also turn on `chrome://flags/#enable-experimental-web-platform-features`.
